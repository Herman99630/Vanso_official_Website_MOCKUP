# Vanso Official Website Mockup

Interactive frontend mockup based on the Vanso Figma proposal. It currently contains:

- Homepage
- About
- Download
- Responsive desktop/mobile layouts
- Official Google Play and App Store links
- Presentation placeholders for unconfirmed ratings, reviews and product imagery

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The repository includes `vercel.json` and can be imported directly into Vercel.

## Content notes

This is a review mockup, not the production Vanso website. Claims such as audience reach, ratings, reviews, partner logos and performance data must be confirmed before public launch.
